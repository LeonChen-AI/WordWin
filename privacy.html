自适应翻译（WordWin）隐私说明

更新日期：2026-10-16。适用于 Microsoft Edge 扩展 0.11.1。

核心说明

本扩展帮助用户在中英文网页和可提取文字的 PDF 中学习英语。扩展没有开发者运营的数据中转服务器，不向开发者上传浏览内容、API Key 或生词本，也不包含广告追踪、分析统计 SDK 或数据出售功能。

用户需要自行配置模型服务商、接口地址、模型和 API Key。模型服务可能收费；其数据保留、处理地区及使用规则由该服务商的条款和隐私政策决定。

何时发送哪些数据

点击网页翻译后，需要处理的中英文正文、句子和提示词会直接发送给用户配置的模型接口。请求包含用于认证的 API Key、所选模型、英语等级和相关翻译偏好。默认不开启自动翻译；若用户开启自动翻译，或在翻译运行期间跳转页面，后续页面也可能按该设置继续处理。并非每次发送前都会再次询问。

PDF 文件在本机解析和绘制。打开本地 PDF、翻页和放大原图不会调用模型；点击翻译后，阅读区域及邻近预加载范围内的提取文字会发送给配置的模型接口。扩展不将整个 PDF 文件或图像上传给模型，不执行图片 OCR 或视觉理解。使用公开 PDF 链接时，浏览器需要向该链接的服务器请求文件，该服务器可接收正常网络请求信息，如 IP 地址。

使用连接测试、等级校准、单词详情，或将生词加入词汇本后自动补充词义、音标和例句时，也会向所配置的模型接口发送相应测试提示、校准材料或单词。这些调用可能产生模型服务费用。

发音使用浏览器的语音合成能力。语音是否在本机完成由所选系统/浏览器语音决定，相关处理遵循对应语音服务的规则。

在本机保存的数据

以下信息保存在当前浏览器配置文件的扩展本地存储中，本扩展不主动通过浏览器同步功能同步这些信息：

  • API Key、各服务商配置、接口地址、模型名称。
  • 英语等级、自定义提示词、显示偏好及自动翻译设置。
  • 生词、释义、例句、复习状态，以及用户保存生词时的来源页面标题、URL 和上下文。
  • 按时间、模型和服务商汇总的请求次数与 token 用量；写入统计时清理超过 30 天的历史记录。

翻译缓存保存在扩展后台运行期间的内存中。扩展本地存储不应被视为独立的加密密码保险库；请妥善保护设备与浏览器配置文件。

控制与清除

可以取消网页翻译、停止 PDF 翻译及关闭自动翻译。取消不会撤回模型服务商已经收到的请求，也不能保证已处理请求退费。

可以在设置中修改服务商配置、清空用量统计，在生词本中删除记录或清空生词本。若需清除所有已存配置（包括曾使用的服务商密钥），可通过 Edge 的扩展管理移除此扩展；自行导出的文件及模型服务商保留的数据不会因此被清除。开发者没有服务器端副本可代为删除。

权限用途

storage 用于保存设置、密钥、生词本及用量记录。activeTab 用于用户操作扩展时识别当前页面并执行翻译控制。普通网页上的内容脚本用于读取可处理的正文、呈现词汇提示和译文；网站访问范围用于支持不同网站及动态内容。扩展不请求摄像头、麦克风、地理位置、浏览器历史记录或 Cookie 读取权限。

不会将输入框、编辑区和代码块作为普通正文发送。但普通网页正文或 PDF 本身可能包含个人或敏感信息；请仅对你愿意发送给所选模型服务商的内容启用翻译。用户填写的自定义接口地址决定数据接收方，请确认地址可信。
