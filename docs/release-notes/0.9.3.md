# 自适应翻译 0.9.3 更新说明

`0.9.3` 是一次面向实际阅读体验的稳定性更新，重点改善生词筛选、段落排版和中英文联动高亮。

## 主要变化

### 生词筛选更准确

- 短导航、按钮和标题不再因为只有一两个词就被全部翻译。
- 模型会返回词汇难度，扩展再按照用户选择的 L1-L5 阅读等级进行二次过滤。
- 常用词增加本地保护，减少模型偶发误判带来的多余标注。
- 没有合适生词时允许返回空结果，不再为了“必须有结果”而勉强标注。

### 中英文对照更稳定

- 段落译文与英文原文保持相同内容宽度。
- 复杂 Flex、Grid 和交互容器只在结构安全时插入译文，降低网页错位风险。
- 鼠标悬停英文或中文句子时，两侧同步使用明黄色高亮。
- 鼠标移出后会可靠清除高亮，且高亮过程不再引起换行或排版抖动。

### 操作界面更简洁

- 扫描范围固定为全面模式，不再显示无法生效的模式选择。
- 字号调节按钮改为独立的减号和加号，避免图形重叠。
- API 连接测试过程只显示状态文字，不再使用多余的加载图形。

### 授权方式调整

- 从本版本起，个人学习、研究和其他非商业用途免费。
- 公司、组织或个人用于商业目的时，需要事先取得单独的付费商业授权。
- `0.9.1` 及更早版本继续遵循其发布时随附的许可证。

## 升级说明

- 从 `0.9.1` 升级时，原有 API 配置和用户设置会继续保留。
- 旧版内置默认 Prompt 会自动迁移到新规则；用户自行修改过的 Prompt 不会被覆盖。
- 旧的扫描范围设置会统一迁移为全面模式。

## 版本信息

- 扩展版本：`0.9.3`
- 中文名称：自适应翻译
- 英文代码名称：AdaptiveTranslation
